# Information Architecture

Status: APPROVED
Revised and Approved: 2026-08-25
Supersedes: Version approved 2026-08-19

## Purpose

이 문서는 `docs/00_STRATEGY.md`와 D-017에 따라 Writing 중심 초기 공개판의 정보 구조와 각 화면의 역할을 정의한다.

내부 route와 component 식별자는 영어를 사용할 수 있지만 사용자-facing 문구는 한국어를 기본으로 한다. 사이트는 자기소개나 경력 탐색보다 글의 발견과 읽기를 먼저 제공한다.

## Core Structure

```text
/
├─ /writing/[slug]
├─ /rss.xml
└─ /404
```

`/`는 별도 소개 Home과 Writing 목록을 나누지 않고 **Home / Writing Archive** 역할을 함께 수행한다.

초기 public route에서 제외한다.

```text
/writing
/work
/work/[slug]
/now
/about
```

제외된 화면의 기존 콘텐츠와 구현 이력은 보존할 수 있지만 public build, sitemap, navigation에서는 노출하지 않는다.

## Global Navigation

초기 공개판에는 별도의 주 메뉴를 두지 않는다.

- Header의 사이트 이름은 `/`로 이동한다.
- Writing Detail에서는 Header의 사이트 이름과 본문 하단 링크를 통해 `/`로 돌아간다.
- RSS는 Footer에서 제공한다.

사이트에 단일 콘텐츠 영역만 있는 상태에서 `Home`과 `Writing`을 중복 메뉴로 만들지 않는다.

## Home / Writing Archive `/`

### Question

방문자가 다음 질문에 바로 답을 얻도록 한다.

> 이곳에는 어떤 글이 있고, 지금 무엇을 읽을 수 있는가?

### Structure

```text
Site Header
↓
Writing Intro
↓
Writing Archive
↓
Site Footer
```

### Writing Intro

역할:

- 사이트가 이병관이 쓴 글의 공개 아카이브임을 짧게 설명한다.
- 일, AI, 생활, 육아 등 서로 다른 주제가 함께 올라올 수 있음을 자연스럽게 전달한다.
- 직업과 경력을 첫 문장이나 대표 제목으로 내세우지 않는다.

권장 분량은 제목 하나와 1~2개의 짧은 문단이다. 별도 About 페이지를 대신하는 상세 자기소개를 넣지 않는다.

### Writing Archive

- 공개된 글과 노트만 노출한다.
- 최신 게시일 순으로 정렬한다.
- 날짜와 제목을 중심으로 보여준다.
- 설명, Topic, Series, type은 목록의 필수 노출 정보가 아니다.
- 글 제목은 Writing Detail로 연결한다.
- Featured, 추천글, 카드형 큐레이션, 분류 navigation을 초기에는 제공하지 않는다.

공개 글이 없는 상태를 placeholder나 fixture로 채우지 않는다. 실제 공개 시점에는 사용자 검토를 마친 글이 최소 하나 존재해야 한다.

## Writing Detail `/writing/[slug]`

### Question

> 공유받거나 발견한 글을 방해 없이 읽고, 글의 출처와 공개 시점을 이해할 수 있는가?

### Structure

```text
Site Header
↓
Article Header
↓
Article Body
↓
Back to Writing Archive
↓
Site Footer
```

### Article Header

최소 노출 정보:

- title
- publishedAt
- type (`글` / `노트`)

선택 노출 정보:

- updatedAt
- series

`updatedAt`이 존재하고 `publishedAt`과 다를 경우 수정 시점을 표시할 수 있어야 한다. Topic은 콘텐츠 metadata로 보존하되 초기 화면에서 반드시 노출하지 않는다.

### Article Body

- 읽기 폭과 행간을 우선한다.
- Markdown의 heading, paragraph, list, blockquote, link를 안정적으로 표현한다.
- 별도 CTA, 관련 글 추천, 댓글, 공유 버튼을 초기에는 넣지 않는다.

### Canonical Sharing

각 Writing Detail은 다음을 만족한다.

- 독립된 public URL
- canonical URL
- title과 description 기반의 기본 Open Graph metadata
- 특정 플랫폼 로그인 없이 접근 가능
- draft 글은 static path, sitemap, RSS에서 제외

---

## Writing Content Model

필수 metadata:

```text
title
description
publishedAt
type: essay | note
draft
```

선택 또는 확장 metadata:

```text
updatedAt
topics[]
series
```

### Writing Types

- **Essay / 글**: 하나의 생각을 어느 정도 정리한 콘텐츠
- **Note / 노트**: 관찰, 질문, 짧은 생각, 아직 결론 내리지 않은 콘텐츠

두 타입은 동일한 목록과 상세 route를 사용한다. 별도 Notes, Essays landing page를 만들지 않는다.

### Parenting / Series Rule

`아빠들의 육아 대화`는 별도 route나 상위 navigation으로 만들지 않는다. Writing의 `series` 또는 `topics` metadata로만 시작한다.

---

## RSS `/rss.xml`

- 공개된 Writing만 최신순으로 포함한다.
- draft 콘텐츠와 Work 콘텐츠를 포함하지 않는다.
- 각 항목은 해당 Writing Detail의 canonical path를 가리킨다.

## 404

- 요청한 페이지가 없음을 짧게 알린다.
- `/`의 글 목록으로 돌아가는 경로를 제공한다.
- 제외된 이전 public route도 새 build에서는 404가 되어야 한다.

## Footer

최소한으로 유지한다.

- 저자 이름 또는 copyright
- 사이트 성격을 설명하는 짧은 문장
- RSS

실제로 운영하지 않는 외부 채널, 연락 수단, 소셜 링크는 미리 추가하지 않는다.

## Core User Journeys

### A. Shared Writing Reader

```text
External Channel or Direct Link
→ Writing Detail
→ Home / Writing Archive
→ Other Writing
```

### B. Archive Visitor

```text
Home / Writing Archive
→ Writing Detail
→ Home / Writing Archive
```

### C. Future Self

```text
Home / Writing Archive
→ Past Writing
→ Published / Updated Metadata
```

## Cold Start and Growth

> 콘텐츠 모델은 미래의 축적을 허용하고, 실제 UI는 현재 읽을 가치가 있는 콘텐츠만큼만 보여준다.

| Capability | Initial Public Site | Revisit Condition |
|---|---|---|
| Writing Archive | 날짜 + 제목 목록 | 유지 |
| Writing type | metadata + 상세 표시 | 타입별 탐색 필요 확인 |
| Topics | metadata only | 주제별 글이 충분히 축적 |
| Series | metadata only | 연재별 탐색 가치 확인 |
| Related Writing | 없음 | 연결할 실제 글이 축적 |
| Work / Now / About | public 제외 | 별도 전략 변경 승인 |

## Out of Scope

- Work / Work Detail
- Now
- 별도 About
- Topic / Series landing page
- 검색과 태그 시스템
- 댓글
- 뉴스레터
- 로그인
- 공유 버튼 모음
- 조회수와 좋아요
- 외부 채널 자동 배포
